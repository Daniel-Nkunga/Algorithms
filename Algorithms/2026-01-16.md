## Data Structures
- **Data structure**: a way to represent data and the relationships among different pieces of data
- **Linear data structure**: data structures that can be arranged in a sequence or linear list
	- Ex: array list

- **Non-linear data structure**: data structures that cannot necessarily be arranged in a linear list
	- Ex: tree, graph
- **Array**: a collection of similar data types
	- Can either be dynamic or static in size (array vs vector in C++)

## Linked List
- **Linked List**: an array where each element (node) in the list points to the next element in the list
	- **Head**: first element in the list
	- **Nodes**: made of two components -- data and pointer
	- Considered both linear or non-linear depending how the linked list is made
- **Double Linked List**: an array where each element (node) in the list points to both the previous element in the list and the next element

## Stacks and Queues
- **Stack**: a data structure that rigidly follows FILO to interact with the data
- **Queue**: a data structure that rigidly follows FIFO to interact with the data
